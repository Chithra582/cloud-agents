# WebSocket Mesh Communication

## Overview
This skill mediates bidirectional real-time communication between millions of connected clients and persistent edge agents.

## Capabilities
- Manages persistent WebSocket connections with zero idle compute cost.
- Supports tag-based client broadcasting and message filtering.
- Implements auto-ping/auto-pong TCP keepalive handshakes.
